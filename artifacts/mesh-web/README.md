# MeshTalk Web App

A modern web interface for the MeshTalk P2P mesh networking application.

## Quick Start

From the project root, run:

```bash
pnpm install
pnpm --filter @workspace/mesh-web run dev
```

The app will open at `http://localhost:3001`

## Features

- 🌐 Network Topology visualization - See connected peers
- 💬 Direct Messaging - Send 1-on-1 messages
- 👥 Group Chats - Communicate with multiple peers
- ⚙️ Settings - Configure your node
- 📡 Relay Mode - Toggle relay functionality
- 🔋 Battery Monitor - Track device power level

## Architecture

Built with:
- **Vite** - Lightning fast dev server
- **React 19** - Modern UI framework
- **TypeScript** - Type safety
- **Tailwind CSS** - Utility-first styling
- **React Query** - Server state management
